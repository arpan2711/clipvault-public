# ClipVault

**A free, ad-free game recorder for Windows, built for League of Legends.**

> 🚧 ClipVault isn't released yet. This repo is where downloads, updates and bug reports will live. Watch it (top right → Watch → Custom → Releases) to hear when the first version is out.

## What it does

- **Death cam**: a few seconds after you die, a small replay of how it happened plays over the game, so you can see what went wrong while you wait to respawn. Blow it up, replay it or close it with hotkeys that never clash with League (Ctrl+Shift+Alt+F / R / X). It can replay your kills too.
- **Automatic highlights**: kills, deaths, multikills and objectives are clipped by themselves, using Riot's official Live Client Data API.
- **Instant replay**: save the last seconds of gameplay with one hotkey.
- **Full match recordings** with every key moment marked on the timeline, plus a minimap reel and your keyboard and mouse inputs next to each clip.
- **Game sound only** by default, so Discord and music stay out of your clips.
- **No ads, no account, no uploads, no watermark.** Everything stays on your PC.

## Found a bug?

In ClipVault: **Settings → About → Report a bug** (or the tray menu). It fills in an issue here with your system info, with file paths and player names removed. You can also [open an issue](../../issues/new?template=bug_report.md) by hand.
